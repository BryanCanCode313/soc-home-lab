# Ubuntu Splunk Integration Evidence

This folder contains redacted screenshots documenting the integration of an Ubuntu Server VM with Splunk Universal Forwarder and Splunk Enterprise.

## Evidence

Screenshots in this folder demonstrate:

- Splunk Universal Forwarder configuration
- TCP 9997 connectivity testing
- Active forwarding to Splunk Enterprise
- Apache log monitoring
- SSH authentication logging through systemd/journald

> Sensitive information such as IP addresses, usernames, hostnames, and other identifying information must be redacted from screenshots before upload.
